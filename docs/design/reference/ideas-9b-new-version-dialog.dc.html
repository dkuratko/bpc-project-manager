Notes — creating a version
Version or rendition — the question the dialog is really asking
A new version is a different answer to the customer’s problem: different equipment, different approach. A new rendition is the same answer, priced or worded again. Getting this wrong is the most likely user error in the whole application, which is why the “Why” field exists — writing the reason forces the distinction.
Copy is the default because copy is the truth
Almost every version starts as a variation. Starting empty is offered second because it is rarer, not because it is worse.
Problems I see
· Copying procurement decisions is arguable. D0 inherits A0’s concrete vendor and its quote date, which will be stale on a version created weeks later. Quantities should copy; prices maybe should not.
· No way to create a version by copying two others. “A’s site work with B’s equipment” is a real request and this dialog cannot express it.
· Letter D is assigned before Create. If two estimators open this dialog at once they both see D. Assign on save.
