An add option is never subtracted — it was never in the quoted total.
The estimate's number is the base; options are offered beside it. Base lines subtract when the PO takes less of them, options add when it takes them, and simply do not appear when it does not. A line reading Less J.O1 ($4,850.00) would claim the customer gave back something they never bought.

Price is arithmetic and needs no button. Margin is not. Cost is pooled — an effective rate is total ÷ required, so ordinary drift is noise ($7.59 on the ramada, 0.02% of the job) but a crossed threshold is not. [ Check margin ] runs the real recompute; skipping it loses nothing, REV1 computes the same figures when it opens.

This popup writes nothing. The result hands back to Record approval, and REV1 exists only once Record is pressed there. Cancel the approval and the revision was never real.
